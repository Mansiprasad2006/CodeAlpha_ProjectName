# Stock Portfolio Tracker - Requirements
#
# This project uses ONLY Python's built-in standard library:
#   - tkinter   (GUI)
#   - csv       (CSV file handling)
#   - os        (file path handling)
#   - datetime  (timestamps for saved reports)
#
# No external packages need to be installed via pip.
# You only need a standard Python 3.8+ installation.
#
# NOTE for Windows/Mac users:
# tkinter ships with the official Python installer by default.
#
# NOTE for Linux users (if tkinter is missing):
#   Ubuntu/Debian:   sudo apt-get install python3-tk
#   Fedora:          sudo dnf install python3-tkinter
